# 적합한 장르·작업과 검증 한계

## 가장 적합한 작업

스프라이트 기반 2D 액션 RPG/벨트스크롤의 한국어 대사, 파티·장비·인벤토리 흐름, 동작 루프/발 위치/이벤트 타이밍, 무기·속성·피격 FX의 인과, 맵 접지/깊이, 기존 모션을 활용한 도트 시네마틱, 제작 기록과 인계에 가장 가깝다. 이 주제의 설계·리뷰 절차를 제공하며 엔진 기능을 구현한 라이브러리는 아니다.

2D 메트로배니아/탑다운 RPG/서사 게임은 일부 모듈을 사용할 수 있지만 이동/원근/전투/진행 구조를 먼저 조정한다. 턴제·퍼즐·전략 게임에 벨트스크롤 동작과 HUD를 강제하지 않는다. 3D/VR/온라인 게임에서는 대사나 인계 같은 공통 부분만 제한적으로 참고할 수 있고 전문 구현의 검증을 대신하지 못한다.

## 포함하지 않는 것

특정 상용 게임의 코드/원화/추출 자산, 비공개 게임의 설정/대사/원본/저장, 생성 API/모델 계정, MCP 도구/서버, 자동 게임 생성기, Unity/Unreal/Godot 어댑터, 유료 모션 생성 권한을 포함하지 않는다. 설치만으로 인터넷·화면·파일·생성 도구가 새로 생기지 않는다. 사용 가능한 도구/권한 안에서 해당 작업만 진행한다.

## 현재 증거와 한계

초기 독립 텍스트 검증은 모션/화면 FPS 실험 계획, 긴 이름 드롭다운의 좁은 수정, 첫 조우 대사 정합성, 일반 SaaS의 적용 제외를 다뤘다. 이는 실제 영상 재생·엔진 통합·다언어 번역·시장 성공·장기 밸런스의 검증이 아니다. 자동 선택의 정확도도 보장하지 않는다. 현재 검증 범위와 실행 명령은 저장소 VALIDATION.md에서 확인한다.

출처가 한 제작 흐름에 치우칠 수 있다. 장르/플랫폼/아트가 다르면 실제 유저 자료와 대표 장면으로 다시 조사한다. 12fps·특정 해상도·원형 게이지·3인 파티·특정 서비스 우선순위 같은 개별 선택을 기본 상수로 가져오지 않는다.

## 맞지 않는 요청에 응답

전체가 범위 밖이면 그 사실과 필요한 전문 자료/도구를 설명한다. 일부만 맞으면 적용할 모듈과 미검증 부분을 구분한다. 자료가 없으면 접근/시청/검수를 했다고 쓰지 않는다. 사용자의 한 예시를 모든 장르의 정답으로 일반화하지 않는다.
