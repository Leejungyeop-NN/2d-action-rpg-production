# 2D 액션 RPG 제작 지침

스프라이트 기반 2D 액션 RPG·벨트스크롤 제작에서 축적한 판단과 검수 절차를 에이전트 스킬로 제공한다. 모든 장르의 제작을 보장하는 자동 게임 생성기나 엔진은 아니다.

주로 한국어 대사/서사, 동작·루프·발사 이벤트, 무기/속성/피격 이펙트, 파티·장비·인벤토리 UI, 맵 접지·도트 연출, 리서치·핸드오프에 적합하다. 다른 2D 장르는 해당 모듈을 조정해 사용한다. 3D/VR/네트워크/경쟁 밸런스/엔진별 구현과 타 언어 문체는 검증 범위 밖이다.

구조·링크 검사와 제한된 텍스트 행동 검증을 구분한다. 실제 게임 재생/시각 품질/출시 성과의 보증은 아니다. 프로젝트 전용 설정·원고·코드·에셋·저장·로컬 경로는 배포하지 않는다. MCP 서버·API·유료 생성 권한도 포함하지 않는다.

설치 명령과 현재 검증/제출 상태는 [README](../README.md), [VALIDATION](../VALIDATION.md), [SUBMISSION](../SUBMISSION.md)을 따른다. MIT는 이 저장소에 포함된 공통 지침에만 적용한다.
